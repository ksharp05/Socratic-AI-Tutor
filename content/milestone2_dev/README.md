# Milestone 2 development quiz items

This directory contains six developer-authored synthetic quadratic-equation questions intended for the local Milestone 2 demonstration. Each item permits `quiz` and `diagnostic` use and excludes `practice`; its exact usage policy is included in any teacher-approved payload. The file contains problem givens and prompts, not answer keys. The maths service computes keys from the givens and requires its two calculation paths to agree.

The questions are development content. Their `pending_human_review` status remains unchanged until an actual reviewer acts through an appropriate review process. A synthetic teacher identity used in tests is not human approval. These items are not independently authored final held-out cases and must not be used to claim independent evaluation or measured learning.

The frozen v0.10.0 practice dataset is separate and remains practice-only. This small pack covers quadratic equations; it does not cover arithmetic progressions or trigonometry. New packs need explicit usage modes, provenance, mathematical checks and the same teacher-publication workflow before use.
