# Expanded conversational dataset: integration contracts

The development data remains local and is not part of this repository. See the [dataset report](../datasets/DATASET_REPORT.md) for its size, provenance and review status.

Schemas, proposed taxonomy corrections, pending review policy, reviewer templates and the export manifest are retained here to support future integrations. Pending or synthetic data is not human-approved, and no held-out content should be used for tuning. Inspect the policy and manifest before admitting any data.

Technical references: [file index and schemas](01_FILE_INDEX_AND_SCHEMA.md), [review guide](03_REVIEW_GUIDE.md), [integration design](05_INTEGRATION_DESIGN.md), and [proposed evaluation protocol](06_EVALUATION_PROTOCOL.md). Some refer to local development evidence that is excluded from Git.
