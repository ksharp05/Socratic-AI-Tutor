# v1.1 — final course submission, 14 November 2026

v1.1 is v1.0 ([release note](2026-11-12-v1.0.md)) plus the team's work from 13–14 November. The system, the experiments and the E1–E4 results are unchanged. Every number is still development evidence. No held-out run was made.

- **Safety.**
  - D-8: crisis-mention masking is off by default. It hid 7 of 8 disguised disclosures in new probes.
  - A CI gate, `python -m tutor_eval.beta_front_door`, runs about 500 development cases through the beta's screens and fails on any regression. `tests/regressions/` holds the failure-to-test rule.
- **App security (R4, PR #30).** Four fixes, one test each:
  - secrecy promises written with curly apostrophes are now caught;
  - the maths checker stops waiting after 2 s;
  - the beta no longer publishes `/beta/openapi.json`;
  - session locks are bounded to 256 stripes.
- **Practice (R3, PR #29).** "Check my step" feedback for triangle-ratio steps in English, Hindi and Hinglish. It never grades or reveals the answer. R3's review added 174 tests. Its two bugs, C2-2 and C2-3, are fixed. C2-1 is open for the team.
- **Beta chat.**
  - Enter sends a message (db49b7d, in production).
  - A short supportive reply for stress messages, which is not saved.
  - A retrieval cache and a single write transaction, from the latency review in `Docs/report/beta-latency/`.
- **Pre-registration (D-9).** The B3 safety pre-registration is frozen at tag `prereg-safety-b3`. Its sealed set is not written yet.
- **Docs.** 93 superseded files were removed. They remain at tag `docs-archive-2026-11-14`. Start at `Docs/README.md`.
- **Tests.** 3,317 passed, 23 skipped (local run, 14 Nov). The registry check, the C1 and dev-smoke harness gates, the front-door gate and the security gate all pass.
- **Production.** It is unchanged and runs Beta `db49b7d` (`dpl_9uoVZqtLgPJYVEARmFnLf8BBvPFH`). The 13–14 Nov changes are in the repository but not deployed.
- **Known limits.** The v1.0 limits still apply. The provider key expires on 16 Nov 2026. C2-1 and the F2 softer-reply option are open.
