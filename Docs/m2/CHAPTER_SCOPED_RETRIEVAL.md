# Chapter-scoped connected conversations

The connected graph tutor now accepts a chapter choice for Class 10 Quadratic Equations, Arithmetic Progressions (AP), or Introduction to Trigonometry. Each conversation is pinned to its selected chapter. The default `poc_cards` retriever builds a separate BM25 index for each chapter and searches only the selected index. Its 22 local normalized reference cards comprise five quadratic, eight AP and nine trigonometry cards. These cards are developer-authored teaching references with textbook anchors; they are not verified quotations or the complete Class 8–12 textbook corpus. Their human content review remains pending. An anchor or PDF hash does not establish accuracy or redistribution rights.

The connected UI provides a chapter selector before a conversation begins; start a new conversation to change chapters. It restores the chapter for a resumed session. AP and trigonometry support source-backed conversations and teacher-approved checked practice for the explicitly supported families described in [chapter practice](CHAPTER_PRACTICE.md). Quizzes, chapter-specific misconception diagnosis and learner plans are not connected. Quadratic teacher-published questions cannot be served in those chapters. Teacher approval and the existing permitted-mode checks still apply to quadratic practice and quizzes. The local stub produces deterministic fallback responses; natural conversation quality with a live model is unverified.

## API and citation history

`POST /chat` accepts optional `chapter`: `quadratic_equations`, `arithmetic_progressions`, or `trigonometry`. A new session defaults to quadratics if omitted; on an existing session omission preserves its chapter. A conflicting value returns 409, and an unsupported value returns 422. The recognized urgent-message path can return an unsaved safety handoff even if the requested chapter conflicts. Responses and `GET /chat/{session_id}/history` report the pinned chapter.

For new replies, citation details are snapshots of the actual retrieved references cited in that reply, including their text, review status, source ID, source PDF hash, URL and page/section where available. A `reference_sha256` covers the serialized snapshot and can detect accidental changes; it is not a signature and cannot protect against a privileged writer changing both content and hash. Old messages without saved snapshots are not retroactively attributed to the current card. Graph checkpoints now retain these reference excerpts along with conversation state. Retention and deletion workflows for that state remain unverified; source access and permitted use need separate confirmation.

## Evidence and remaining work

Offline synthetic tests cover chapter isolation, session pinning, invalid requests, unavailable AP/trigonometry quizzes and plans, urgent-message handling, and citation history including changed current-card text. An assistant-operated localhost browser used a stub model and synthetic identities to check separate AP/trigonometry conversations, source anchors, chapter restoration and unavailable assessment controls; the AP refresh and saved reference were also rechecked in the browser after the snapshot fix; changed-current-card preservation was checked in automated tests. It is not evidence of an educator review, a live model, actual learning outcomes or complete accessibility. See [verification](VERIFICATION.md) and [connected journey](CONNECTED_GRAPH_JOURNEY.md).
