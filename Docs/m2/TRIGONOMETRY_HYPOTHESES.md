# Checked trigonometry error hypotheses

For a teacher-published right-triangle-ratio practice item, the maths service can now compare an incorrect exact scalar answer with three public provisional rules: retaining the original angle's side labels (`tr_m01`), using adjacent/hypotenuse for sine (`tr_m02`), and reversing tangent (`tr_m04`). It uses the registered problem's triangle and reference angle. Arbitrary learner-supplied problems and active quizzes do not use this practice diagnosis path.

A unique matching rule produces a focused Socratic question and a **suspected** learner observation with the question ID. Repeated identical answers do not confirm it. Multiple matching rules produce a request for the learner's angle and side labels; the tutor does not select a cause from an ambiguous fraction. A correct answer or an unmatched wrong answer produces no new hypothesis. A generic item hint does not mark the hypothesis addressed, and subsequent numeric successes do not automatically resolve these provisional trigonometry observations. The quadratic plan is preserved; chapter plans still update through their documented quiz workflow. These three rules and prompts remain pending human content review.

Tests cover both tutor configurations, unique and overlapping rule matches, correct and unrelated answers, repeated evidence, ambiguous responses, and preservation of the quadratic plan. All 40 public triangle-ratio practice keys were also checked to ensure a correct answer produces no hypothesis. The first focused run found an assertion expecting the misconception-specific question while the implementation used the generic concept probe; feedback now uses the single misconception-specific probe for a unique trigonometry match. This is automated development evidence, not validated pedagogical diagnosis.

The existing two-card C1/C2 development comparison was rerun without changing its cases or scoring. Both arms still had zero of six practice attempts checked correct and did not name the seeded trigonometry cause: the relevant wrong sine value fits both a reference-angle error and a sine-definition error. Asking for reasoning is appropriate for that ambiguity; no improved evaluation score or teaching effectiveness is claimed. Runs and logs are retained under ignored `Directions/git_delivery/m2_trig_rules_c{1,2}/`. Free-form side-label interpretation, AP misconception diagnosis, human review and live-model evaluation remain open.
