# Continuing an ambiguous triangle answer

After a checked ratio answer matches several supported error rules, the connected graph asks the learner to state their reference angle and side labels. That pending practice question now accepts bounded English replies such as “angle C, opposite 144, adjacent 17, hypotenuse 145” or “I used C. Opposite side is 144, adjacent side is 17 and hypotenuse is 145.” The numbers must come from the current question. The maths tool checks the stated angle and labels against the registered triangle without returning the final ratio key.

When labels fit, the tutor asks which two sides define the requested ratio. It accepts a bounded ordered-side statement such as “sine is opposite divided by the hypotenuse”, checks the requested function and order, and then asks for the exact value. The learner still has to submit and pass a separate final-answer check. A wrong angle or wrong labels produces a focused prompt. Missing or contradictory labels, negated statements, unsupported arithmetic and unit-bearing replies ask for clarification. This is a limited English parser for positive integer/fraction labels; arbitrary reasoning, diagrams and broad natural-language understanding remain unverified. The registered task uses the two acute angles A/C.

A reasoning reply does not create a numeric grade, mastery update, confirmed misconception or completed practice result. The pending probe is retained in the active question checkpoint, including across process restart. A new numeric final answer still goes through the normal grader. Publication revocation and safety routing apply before reasoning checks; active quizzes do not provide this help. Both C1 and C2 use the same checked tool with the existing diagnostician permission and scrubbed response logging. No external model call is needed.

Offline tests cover common sentence forms and punctuation, correct/wrong/reference-conflicting labels, correct/incorrect/ambiguous side-ratio definitions, invalid fractions, decimals, negation, units and incomplete reasoning; they also exercise both configurations, unchanged mastery during reasoning, final grading, revoked approval, quiz isolation and restart recovery. The first focused run exposed a terminal full stop being rejected as a decimal; the numeric boundary now accepts punctuation while leaving unsupported decimals unverified. These are development checks and do not establish human teaching quality or an independent evaluation result.
