# Connected AP and trigonometry practice

The connected graph can propose, review, publish and deliver selected public Class 10 practice questions for Arithmetic Progressions and Introduction to Trigonometry. The added pool has 120 practice-only candidates: 40 AP term questions, 40 AP sum questions and 40 right-triangle trigonometric-ratio questions. These are the existing assistant-authored public dataset records, not newly sourced textbook exercises. All remain pending human content review. The system does not automatically publish them. A teacher proposal binds the selected question, mode and provenance; a teacher must approve that exact payload before a learner receives it.

The tutor pins the learner session to a chapter, chooses a published item for that chapter, checks the key using both existing calculation routes, requests an exact scalar answer, and checks the submitted answer. It also recognises a few explicit English lead-ins, such as “my answer is” and “I think it’s”; it does not interpret arbitrary reasoning. A wrong answer keeps the item open and offers a staged question; a learner can request a reference-backed hint. A scorable attempt updates matching AP/trigonometry concept observations. These experimental estimates are not proof of mastery or learning; teaching and review status remain provisional. Session isolation and publication revocation use the existing graph safeguards. The concept registry is extended for observations. Separate AP/trigonometry plans now update after completed chapter quizzes; trigonometry practice supports three provisional error hypotheses; AP diagnosis remains unavailable. [Chapter quizzes and plans](CHAPTER_QUIZZES_AND_PLANS.md).

Question permissions are not expanded: the new public items permit **practice only**, not quizzes or diagnostics. A separate synthetic development pack supplies AP/trigonometry quiz questions and requires its own teacher approval; review remains pending. Other answer formats and families, including undefined standard values and boolean answers, are not added to this graph practice path. Tutor responses use the offline deterministic template in stub mode; natural-language tutoring with a real model remains unverified.

## Development evidence

For every one of the 120 candidate problems, a separate exact arithmetic check computed AP terms or sums by iterating the sequence, or calculated the trigonometric side ratio with rational fractions and the specified reference angle. Its result agreed with the existing checked key and was accepted by the grader. This confirms those arithmetic answers under the represented givens; it does not validate every problem statement, hint, source anchor or pedagogical claim. Automated synthetic API tests also cover teacher approval, chapter-specific hints, wrong/correct attempts and concept updates. An assistant-operated localhost walkthrough used a synthetic teacher and learner, approved one problem per chapter, and observed wrong then correct responses in each. This is neither a live-model evaluation nor human educator approval. See [verification](VERIFICATION.md).

## Reproducing a local demonstration

Start the authenticated local graph and beta mount using [the run guide](../RUN_GUIDE.md). In the teacher interface, propose a `practice` set for `ap03` (AP term/sum) or `tr01` (triangle ratio), inspect the actual items and review metadata, edit if needed, then approve. Select the matching chapter in Connected maths tutor, start a new conversation, and type `practice`. A different chapter needs its own published question; selecting one does not grant quiz permission. Reviewers must independently examine the content before any actual learner-facing release.


Checked right-triangle practice now supports three provisional error hypotheses with explicit ambiguity handling. See [trigonometry hypotheses](TRIGONOMETRY_HYPOTHESES.md); broader diagnosis remains incomplete.
